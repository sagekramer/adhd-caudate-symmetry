Background

Research question

Attention-Deficit Hyperactivity Disorder (ADHD) is one of the most common neurodevelopmental conditions in adolescents. While structural MRI scans allow us to examine the brain, much of this data has yet to be intensively studied and analyzed. This project uses the LCPC Transform to conduct a detailed shape analysis of the caudate nucleus — a deep brain structure implicated in ADHD — to find subtle morphometric differences that traditional volumetric measurements would miss.

We expect to find a larger difference in symmetry between the left and right caudate nucleus of an adolescent diagnosed with ADHD compared to a neurotypical adolescent.

This hypothesis is grounded in Schrimsher et al. (2002), which found caudate nucleus volume asymmetry predicts ADHD symptomatology in children.

Slice selection

Identifying the axial slice of interest

Each MRI was aligned according to GRIC coordinates. In the sagittal view, the horizontal slice bisecting the anterior apex of the corpus callosum was identified. The axial view at this position is the slice of interest.

The caudate nucleus — adjacent to the lateral ventricle — was segmented. The putamen, which is adjacent to and sometimes touching the caudate in the axial view, was carefully excluded from all tracings.

Segmentation tool

Brain Structure Boundary Drawer

A custom Python desktop application was built to trace the caudate nucleus boundary on each MRI axial slice. The tool uses an intelligent scissors algorithm — rather than requiring a perfectly hand-drawn outline, the user clicks waypoints near the boundary and the app automatically snaps each path segment to the nearest edge using A* pathfinding on an edge detection cost map.

def build_cost_map(gray):
    sx  = cv2.Sobel(gray, cv2.CV_64F, 1, 0, ksize=3)
    sy  = cv2.Sobel(gray, cv2.CV_64F, 0, 1, ksize=3)
    mag = np.sqrt(sx**2 + sy**2)
    mag = cv2.GaussianBlur(mag, (3, 3), 0)
    mag = mag / (mag.max() + 1e-6)
    canny = cv2.Canny(gray, 30, 90).astype(np.float32) / 255.0
    canny = cv2.GaussianBlur(canny, (5, 5), 1.5)
    canny = canny / (canny.max() + 1e-6)
    combined = np.clip(mag * 0.5 + canny * 0.5, 0, 1)
    return np.clip((1.0 - combined).astype(np.float32), 0.01, 1.0)

Preprocessing protocols

Two analysis tracks

Each subject's caudate masks were preprocessed following two separate protocols. Pure shape removes size differences to compare shape only. At scale preserves native size and is valid because all images were exported at the same magnification (1.5×).

Pure shape analysis

Size-independent
Left side
  • 1Segment & extract blue mask from original image
  • 2Isolate left caudate to its own white canvas
  • 3Rotate by longest internal line (horizontal rotation tool)
  • 4Trim margins to 1 pixel
  • 5Resize width to 400 px, constrain aspect ratio
  • 6Add 100 px padding to all margins
  • 7Rotate 90° clockwise
  • 8Run parallel grid LCPC transform
Right side
  • 1Isolate right caudate to its own white canvas
  • 2Flip horizontally (so midline is to the left)
  • 3–8Same as left side steps 3–8

At scale analysis

Size-preserved
Left side
  • 1Segment & extract blue mask from original image
  • 2Isolate left caudate to its own white canvas
  • 3Run parallel grid LCPC transform directly
Right side
  • 1Isolate right caudate to its own white canvas
  • 2Flip horizontally (so midline is to the left)
  • 3Run parallel grid LCPC transform

Valid because all images were exported at 1.5× zoom consistently across subjects.

Analysis pipeline

LCPC transform — 5 parts

Each preprocessed mask passes through the 5-part parallel grid LCPC pipeline developed by David H. Nguyen, PhD (TSG Lab).

Mask image → Part 1: Stencil → Part 2: Intersections → Part 3: Summed distances → Part 4: FFT → Part 5: Compiled CSV

The final output is one compiled CSV per subject containing FFT magnitude values for both the left and right caudate. These values are used as input for the matched-pairs statistical test comparing ADHD and neurotypical groups.
